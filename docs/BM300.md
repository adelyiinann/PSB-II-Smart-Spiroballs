PENGANTAR

RINGKASAN ISI DOKUMEN

Dokumen Project Proposal BM100 ini disusun sebagai pengajuan resmi pelaksanaan Capstone Design semester 6 Program Studi Teknik Biomedis, Institut Teknologi Sumatera (Itera). Dokumen memuat identifikasi kebutuhan lapangan, rumusan tujuan produk, karakteristik solusi teknis, analisis kelayakan bisnis, perencanaan pengembangan, serta estimasi biaya dan sumber daya untuk proyek Smart SpiroGame.

Smart SpiroGame adalah sistem skrining fungsi paru portabel berbasis incentive spirometer yang diintegrasikan dengan mikrokontroler ESP32, sensor tekanan diferensial MPX5010DP, dan mekanisme gamifikasi interaktif. Sistem dirancang untuk menghasilkan output digital berupa parameter spirometri utama estimasi Forced Vital Capacity (FVC) dan Peak Expiratory Flow Rate (PEFR) yang dibandingkan secara otomatis dengan nilai referensi persamaan prediksi NHANES III. Dengan pendekatan ini, alat dapat berfungsi sebagai instrumen skrining awal yang informatif di fasilitas kesehatan primer tanpa memerlukan spirometer klinis konvensional yang mahal.

KONSEP SISTEM

ARSITEKTUR UTAMA SISTEM

Sistem screening kesehatan paru-paru terdiri atas beberapa bagian utama yaitu:

Sensor MPX5010DP sebagai pendeteksi tekanan udara.

ESP32 sebagai pusat pemrosesan data.

OLED sebagai media tampilan.

Buzzer sebagai indikator alarm (opsional).

Bot Telegram sebagai media monitoring jarak jauh.

Push button sebagai tombol kontrol (opsional).

Adaptor DC atau Laptop sebagai sumber daya.

ADS1115ADC untuk mengubah sinyal analog dari sensor menjadi data digital dengan resolusi lebih tinggi sehingga pembacaan sensor menjadi lebih presisi.

Spirometer Incentive Three Balls sebagai media input embusan napas pengguna dalam proses pengukuran fungsi paru.

Alur kerja sistem dimulai ketika pengguna meniup spirometerballs. Tekanan udara yang dihasilkan akan dibaca oleh sensor MPX5010DP. Data analog dari sensor kemudian diproses oleh ESP32 untuk dihitung nilai tekanan dan estimasi kapasitas paru-paru. Hasil pengukuran ditampilkan pada LCD dan dikirimkan ke Telegram.

Gambar 1. Alur sistem Smart SpiroGame

ALGORITMA UTAMA YANG AKAN DIGUNAKAN

Algoritma utama sistem Smart SpiroGame terdiri dari beberapa tahapan pemrosesan sinyal. Pertama, sinyal analog dari sensor MPX5010DP dibaca melalui pin ADC ESP32 dengan frekuensi sampling 100 Hz. Nilai tegangan dikonversi menjadi nilai tekanan (cmH2O) menggunakan persamaan kalibrasi linier. Selanjutnya, nilai tekanan diintegrasikan secara numerik menggunakan metode trapesoid untuk mendapatkan estimasi laju aliran udara (L/s) dan volume kumulatif (L).

Dari data tersebut, sistem menghitung FVC dan PEFR, lalu membandingkannya dengan nilai referensi NHANES III berdasarkan usia, tinggi badan, dan jenis kelamin pengguna untuk mengklasifikasikan fungsi paru sebagai normal, obstruksi ringan, sedang, atau berat. Hasil akhir ditampilkan di OLED dan dikirimkan melalui Bot Telegram.

Gambar 2. Tahapan algoritma sistem

MODUL ATAU SUB-BLOK YANG MEMENUHI FUNGSI DAN SPESIFIKASI

Sistem Smart SpiroGame terdiri dari lima modul utama:

(1) Subsistem Akuisisi Data sensor MPX5010DP yang terhubung ke pin ADC ESP32 untuk mengukur tekanan udara ekspirasi;

(2) Subsistem Pemrosesan Sinyal firmware ESP32 yang melakukan konversi ADC, komputasi FVC/PEFR, dan klasifikasi fungsi paru berdasarkan NHANES III;

(3) Subsistem Antarmuka Gamifikasi layar OLED 0,96 inci yang menampilkan animasi SpiroGame real-time selama manuver ekspirasi; dan

(4) Subsistem Komunikasi Nirkabel modul Wi-Fi ESP32 yang menghubungkan perangkat ke Telegram API untuk pengiriman laporan otomatis.

Pemodelan Sistem

Pengguna meniupkan udara melalui mouthpiece yang terhubung ke sensor MPX5010DP. Tekanan diferensial diubah menjadi sinyal tegangan analog, dikonversi oleh ADC 16-bit ESP32, dan diproses secara real-time untuk menghitung laju aliran dan volume udara. Hasil perhitungan ditampilkan di layar OLED sebagai visualisasi permainan yang memotivasi pengguna. Setelah pengukuran selesai, parameter FVC dan PEFR dikirim melalui Wi-Fi ke Bot Telegram.

Desain Skematik Rangkaian

Pin VOUT sensor MPX5010DP terhubung ke pin GPIO34 (ADC1_CH6) ESP32 melalui kapasitor bypass 100 nF. VCC sensor dihubungkan ke 5V dari modul converter 16-bit ADS1115. Layar OLED dihubungkan via I2C (SDA: GPIO21, SCL: GPIO22). Dan ESP32 dihubungkan dengan USB cable ke laptop sebagai sistem dan komunikasi serial.

Desain Tataletak PCB

PCB double-layer berukuran 80×50 mm. Komponen aktif utama (ESP32 dan MPX5010DP) ditempatkan di sisi atas dengan jalur sinyal analog dipisahkan dari jalur power. Konektor mouthpiece dan OLED ditempatkan di tepi PCB. Ground plane mengisi seluruh layer bawah untuk kestabilan referensi tegangan.

3.1.2.3 UML/State Diagram/Diagram Penunjang Lain

Gambar 5. State Desain 1

Perubahan keadaan (state) sistem selama perangkat Smart SpiroGame beroperasi. Sistem pertama kali berada pada kondisi idle, yaitu keadaan siaga ketika perangkat belum digunakan dan menunggu interaksi dari pengguna.

Setelah pengguna mulai melakukan input data, sistem berpindah ke state input user. Pada kondisi ini, pengguna memasukkan parameter identitas yang diperlukan sebelum pemeriksaan dilakukan. Selanjutnya sistem memasuki state measurement, yaitu tahap pengukuran ketika sensor mulai membaca tekanan udara dari hembusan pengguna.

Data hasil pengukuran kemudian diproses pada state processing untuk menghitung parameter spirometri dan melakukan analisis hasil pemeriksaan. Setelah proses perhitungan selesai, sistem berpindah ke state displaying result untuk menampilkan hasil pada OLED. Tahap terakhir adalah sending telegram, yaitu proses pengiriman hasil pemeriksaan menuju akun Telegram pengguna melalui jaringan WiFi. Setelah seluruh proses selesai, sistem kembali ke kondisi idle dan siap digunakan kembali untuk sesi berikutnya.

State diagram memiliki lima state: IDLE (menunggu napas), DETECTING (deteksi awal aliran), MEASURING (membaca sensor & update OLED), PROCESSING (komputasi FVC/PEFR & klasifikasi), dan REPORTING (tampil di OLED & kirim Telegram). Use Case: Pasien ↔ 'Melakukan Pengujian Spirometri' dan 'Menerima Hasil Skrining'; Tenaga Kesehatan ↔ 'Memantau Laporan Hasil Skrining Pasien'.

3.2ALTERNATIF DESAIN 2

3.2.1 Pemodelan Fungsional Sistem

Alternatif Desain 2 merupakan pengembangan dari Desain 1 dengan penambahan sistem redundansi sensor dan penyimpanan data lokal untuk meningkatkan akurasi serta reliabilitas sistem. Pada desain ini digunakan sensor tekanan MPX5010DP sebagai sensor utama dan sensor aliran udara hot-wire sebagai sensor verifikasi silang terhadap hasil pembacaan tekanan udara. Selain itu, ditambahkan modul SD Card berbasis SPI sebagai media penyimpanan data sementara apabila koneksi Wi-Fi tidak tersedia, serta buzzer piezoelektrik sebagai umpan balik audio selama proses pemeriksaan berlangsung. Sistem tetap menggunakan ESP32 sebagai pusat pengendali dan Telegram Bot sebagai media pengiriman hasil pemeriksaan secara daring. Dengan adanya penambahan komponen tersebut, sistem diharapkan mampu memberikan hasil pengukuran yang lebih stabil, aman, dan tetap dapat bekerja meskipun koneksi internet terputus sementara..

3.2.1.1 Hardware

Konfigurasi hardware pada Alternatif Desain 2 menggunakan mikrokontroler ESP32 WROOM-32 sebagai pusat pemrosesan data dan komunikasi sistem. Sistem dilengkapi dengan sensor tekanan MPX5010DP sebagai sensor utama untuk mendeteksi tekanan udara dari embusan napas pengguna, serta sensor hot-wire sebagai sensor tambahan untuk melakukan verifikasi silang terhadap data aliran udara.

Sebagai fitur tambahan dibandingkan Desain 1, sistem juga menggunakan modul SD Card SPI untuk penyimpanan data lokal ketika jaringan internet tidak tersedia. Data yang tersimpan nantinya dapat diunggah kembali secara batch setelah koneksi kembali normal. Sistem turut dilengkapi buzzer piezoelektrik 5V sebagai indikator suara selama proses pemeriksaan berlangsung. Seluruh rangkaian memperoleh catu daya dari laptop melalui kabel USB yang sekaligus digunakan untuk monitoring sistem dan akses Telegram..

3.2.1.3 Pemodelan Sistem

Pemodelan sistem pada Alternatif Desain 2 dimulai ketika pengguna menekan tombol mulai dan melakukan embusan napas melalui spirometer incentive berbentuk tiga bola. Sensor MPX5010DP membaca perubahan tekanan udara secara real-time, kemudian sensor hot-wire melakukan verifikasi silang terhadap kestabilan dan validitas data yang diperoleh. Proses validasi meliputi pengecekan rentang nilai, stabilitas sinyal, pendeteksian noise, serta deteksi data outlier.

Apabila data dinyatakan valid, sistem melanjutkan ke tahap komputasi parameter spirometri seperti FVC, PEFR, FEV1/FVC, dan persentase prediksi (%Pred). Hasil pengolahan kemudian ditampilkan pada OLED dalam bentuk angka maupun grafik sederhana. Jika koneksi Wi-Fi tersedia, data hasil pemeriksaan akan langsung dikirimkan ke Telegram Bot. Namun apabila koneksi tidak tersedia, data akan disimpan terlebih dahulu ke SD Card dalam format CSV atau JSON.

Sistem juga melakukan pengecekan koneksi internet secara berkala. Ketika jaringan kembali tersedia, seluruh data yang tersimpan di SD Card akan diunggah secara batch ke Telegram Bot sehingga tidak terjadi kehilangan data hasil pemeriksaan.

4 METODE DAN PROSEDUR PENGUJIAN SISTEM

4.1 Sensor

Pengujian sensor dilakukan untuk memastikan pembacaan MPX5010DP stabil, linear, dan responsif terhadap perubahan tekanan. Pengujian meliputi kalibrasi offset, pembacaan kondisi tanpa hembusan, pembacaan pada beberapa tingkat tekanan, pengujian repeatability, serta pengujian noise. Data sensor direkam dalam satuan tegangan dan dikonversi menjadi tekanan sesuai karakteristik sensor.

4.2 Mikrokontroler

Pengujian mikrokontroler dilakukan pada ESP32 untuk memastikan ADC, I2C, GPIO, Wi-Fi, dan komunikasi Telegram berjalan sesuai fungsi. Parameter yang diamati meliputi keberhasilan pembacaan sensor, kecepatan sampling, stabilitas koneksi Wi-Fi, tampilan OLED, dan waktu pengiriman data ke Telegram.

4.3 Pengujian

Pengujian integrasi dilakukan setelah seluruh modul terpasang. Skenario pengujian mencakup pembacaan sensor, tampilan OLED, respons buzzer/LED, pengolahan data, dan pengiriman hasil ke Telegram. Kriteria keberhasilan adalah sistem dapat memulai pemeriksaan, merekam data hembusan, menghitung nilai estimasi, menampilkan hasil, dan mengirim pesan tanpa error.

Pengujian fungsional: memastikan setiap komponen bekerja sesuai fungsi.

Pengujian integrasi: memastikan aliran data dari sensor ke ESP32, OLED, dan Telegram berjalan.

Pengujian akurasi awal: membandingkan hasil estimasi dengan alat pembanding atau data referensi.

Pengujian pengguna: menilai kemudahan penggunaan, kenyamanan mouthpiece, dan kejelasan instruksi.

Pengujian keamanan dasar: memastikan rangkaian tertutup casing, tidak ada kabel terbuka, dan mouthpiece dapat diganti.

4.4 Pengujian Sensor

Hubungkan sensor MPX5010DP ke rangkaian ESP32 dan pastikan catu daya sesuai.

Lakukan pembacaan awal tanpa tekanan untuk menentukan offset.

Berikan tekanan bertahap menggunakan sumber tekanan sederhana atau hembusan terkontrol.

Catat tegangan keluaran sensor dan nilai ADC pada setiap kondisi.

Ulangi pengukuran minimal tiga kali untuk melihat konsistensi hasil.

Bandingkan nilai hasil konversi dengan referensi atau alat pembanding bila tersedia.

KESIMPULAN

Dokumen Project Proposal ini memaparkan rancangan sistem Smart SpiroGame sebagai solusi inovatif untuk skrining fungsi paru berbasis incentive spirometer portabel. Sistem mengintegrasikan mikrokontroler ESP32, sensor tekanan diferensial MPX5010DP, layar OLED, dan Bot Telegram dalam satu perangkat yang kompak, terjangkau, dan mudah digunakan di fasilitas kesehatan tingkat pertama (FKTP).

Dua alternatif desain telah diusulkan dan dievaluasi: Alternatif Desain 1 yang lebih sederhana dan hemat biaya, serta Alternatif Desain 2 yang lebih redundan dengan penambahan sensor verifikasi silang, modul SD card, dan buzzer audio. Sistem Smart SpiroGame diharapkan dapat berkontribusi nyata dalam mengatasi keterbatasan akses spirometer klinis di puskesmas dan klinik pratama Indonesia, mendukung program skrining PPOK dan asma, serta memanfaatkan gamifikasi untuk meningkatkan kepatuhan dan kualitas manuver spirometri pasien.
